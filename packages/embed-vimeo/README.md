# embed-vimeo

Embed Vimeo videos in [Inkdrop](https://www.inkdrop.app/) notes.

Paste a Vimeo link and it renders as an embedded video player in the preview. A paste-link format option lets you quickly insert the iframe HTML directly in the editor.

## Features

- Renders Vimeo videos inline in the Markdown preview
- Supports `vimeo.com/...` URLs
- Adds a "Vimeo embed" option to the paste-link autocomplete menu for inserting iframe HTML

## Install

```
ipm install embed-vimeo
```

## Usage

1. Paste a Vimeo URL on its own line in a note
2. The preview will render it as an embedded video player
3. When pasting a Vimeo URL, select **Vimeo embed** from the autocomplete menu to insert the iframe HTML directly
